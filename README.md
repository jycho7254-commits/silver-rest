# 둥지 — 중장년층 온라인 마음 쉼터

베이비부머 세대(50~70대)를 위한 온라인 마음 쉼터. 다문화청소년 쉼터 **어울림**(multicultural-youth)의 검증된 아키텍처를 중장년층 타겟으로 전환한 사이트.

## 🌳 브랜드

**둥지** — 인생의 절반 이상을 지나온 세대가 잠시 머물고 쉬어가는 안식처. 젊은 날의 나를 만나고, 인생 2막을 준비하는 공간.

## 타겟 전환 매핑 (어울림 → 둥지)

| 어울림 (다문화청소년) | 둥지 (중장년층) |
|---|---|
| 위기 연락처: 청소년전화 1393 | 자살예방상담 109 |
| 보조: 청소년상담 1388 | 정신건강상담 1577-0199 |
| 프로그램: 다문화 정체성 탐색 | 인생 2막 커리어, 부모 마음, 회고 일기 |
| 음악: K-팝/최신 | 그 시절 애창곡, 가족 콘서트 |
| 다국어 4개국 (한/EN/中/VI) | 한국어 중심 + EN/中 (베트남어는 자녀 세대용 보조) |

## 기능 (어울림 구조 계승)

- **쉼터**: 24시간 온라인, 로그인 없음, 오늘의 따뜻함(31문구 로테이션)
- **마음 주고받기 게시판**: 비밀글(비밀번호 해시), 따뜻해요/힘내요 반응, 운영자 답글
- **함께듣기**: 그 시절 음악 플레이리스트(YT Music 연동), 신청곡
- **마음체크**: PHQ-9 / GAD-7 / WHO-5 (무료 공인 도구, 비저장 채점) + 109 크라이시스 박스
- **프로그램 8종**: 회복의 노래 / 인생 2막 커리어 / 마음온도 36.5 / 부모 마음 쉼터 / 몸과 마음 스트레칭 / 가족 콘서트 / 회고 일기 / 온라인 쉼방
- **상담 신청**: 대면(평택 오피스)/온라인/전화

## 기술 스택

- GitHub Pages 단일 `index.html` (의존성 0)
- Supabase — 기존 프로젝트(puuiviiiltxagoebruuq)에 `dungji_*` 테이블로 격리 (어울림 eoullim_*와 공존, RLS 독립)
- `supabase_setup.sql` — dungji_* 테이블/RLS/마스킹 뷰/삭제 RPC (전부 IF NOT EXISTS — 재실행 안전)

## DB 활성화 절차 (형이 SQL 실행)

1. Supabase Dashboard → SQL Editor → `supabase_setup.sql` 전체 붙여넣기 → Run (전부 IF NOT EXISTS라 안전)
2. 완료 — 사이트/운영툴은 이미 같은 프로젝트 키로 연결됨 (`BOARD_DB_URL/KEY` = 어울림과 동일 프로젝트, 테이블 prefix로 격리)
