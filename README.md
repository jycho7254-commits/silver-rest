# 둥지 — 중장년층 온라인 마음 쉼터

베이비부머 세대(50~70대)를 위한 온라인 마음 쉼터. 다문화청소년 쉼터 **어울림**(multicultural-youth)의 검증된 아키텍처를 중장년층 타겟으로 전환한 사이트.

## 🌳 브랜드

**둥지** — 인생의 절반 이상을 지나온 세대가 잠시 머물고 쉬어가는 안식처. 젊은 날의 나를 만나고, 인생 2막을 준비하는 공간.

## 기능 (어울림 구조 계승)

- **쉼터**: 24시간 온라인, 로그인 없음, 오늘의 따뜻함(31문구 로테이션)
- **마음 주고받기 게시판**: 비밀글(비밀번호 해시), 따뜻해요/힘내요 반응, 운영자 답글 — **서버 공유 활성화 완료**
- **함께듣기**: 그 시절 음악 플레이리스트(YT Music 연동), 신청곡
- **마음체크**: PHQ-9 / GAD-7 / WHO-5 (무료 공인 도구, 비저장 채점) + 109 크라이시스 박스
- **프로그램 8종**: 회복의 노래 / 인생 2막 커리어 / 마음온도 36.5 / 부모 마음 쉼터 / 몸과 마음 스트레칭 / 가족 콘서트 / 회고 일기 / 온라인 쉼방
- **상담 신청**: 대면(평택 오피스)/온라인/전화
